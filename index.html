How it works

From photos to an organised record.

1

Capture photographs

Use the RecordLog camera to capture the photographs you want to keep with the project.

2

Add titles and notes

Add an optional title and note so each photograph has clear context.

3

Generate a structured PDF

Generate a structured PDF containing the project information, photographs and available details.
