Help & Support

Version: 2.0 · Effective date: 08/10/2026

Getting Started

Create and verify an account

From the sign-in screen, select "Sign Up", enter your details and select "Create Account". RecordLog sends a verification email through Firebase Authentication. On the "Check your email" screen, open the link in the email and then select "Continue". You can select "Resend verification email" if needed. If you forget your password, select "Forgot password?" on the sign-in screen to request a password-reset email.

Use RecordLog for everyday documentation

RecordLog is a general-purpose photo documentation and organisation application. You can use it for personal projects, hobbies, home DIY, belongings, collections, equipment and other everyday records. RecordLog documents what you capture and enter; it does not certify, authenticate or independently verify it.

Creating a Project

Start a new project

From "My Projects", select "Create Project". On the "New Project" screen, enter a project name of up to 20 characters, add an optional location of up to 35 characters and choose whether GPS is enabled. Select "Confirm & Start Project". The RecordLog camera then opens automatically.

Project photograph limit

Each project supports a maximum of 12 photographs. You can create multiple projects.

Taking Photographs

Use the in-app camera

After creating a project, the camera opens automatically. To add photographs to an existing editable project, select "Continue Shooting". RecordLog captures new photographs using its in-app camera. Importing photographs from the device photo library is not currently supported.

Camera, photo and location permissions

RecordLog needs camera access to take photographs. While the RecordLog camera is active, the app may request and obtain device location. GPS is optional at the project level. RecordLog stores coordinates with a new photograph only when project GPS is enabled and an appropriate location is available. You can turn GPS off for a project or decline or revoke location permission in device settings.

Capture time

When the shutter is used, RecordLog creates the photograph’s capture date and time from the device. This is a device-generated time, not a server-generated timestamp. Check that the device date, time and time zone are correct before capturing important records.

Optional GPS

When GPS is enabled for the project, RecordLog requests a fresh location when a photograph is captured and stores coordinates only if a location is available. The current app treats GPS as unavailable while offline. GPS accuracy varies with the device, signal and surroundings, particularly indoors or over short distances.

Reviewing and Organising Photographs

Add a title and note

After a photograph is captured, the Photo Review screen lets you add an optional title of up to 20 characters and an optional note of up to 50 characters. RecordLog does not currently provide a separate category, area or label field.

Save and continue

Use "Save & Next Photo" to save the photograph and continue capturing, or "Save & Review All Photos" to save it and return to the project gallery. When replacing an existing photograph, use "Save Photo".

Review and reorder

Review photographs in the project gallery, edit available title and note details, and reorder photographs before generating the PDF. Select "Continue Shooting" while the project remains editable and has fewer than 12 photographs.

SHA-256 Photo Hashes

RecordLog calculates a SHA-256 hash from the image file on the device after capture. A SHA-256 hash is a technical fingerprint that can help determine whether two file contents differ. It does not certify the photograph, prove when or where it was taken, identify who captured it, or independently establish authenticity.

Generating, Locking and Sharing a PDF

Generate the project PDF

Select "Generate PDF" after reviewing the project, then confirm with "Generate". RecordLog creates a structured PDF locally from the project information, available photographs and available details.

Internet connection and locking

RecordLog requires an internet connection to begin the PDF process and to complete the project-locking step. The PDF is generated locally, and the system sharing interface may open before the final online lock succeeds. If connectivity is lost before locking completes, a PDF may already exist or have been shared even though the project remains editable. When RecordLog confirms that locking has completed, the project is locked against further editing. Create a new project if you need a revised record.

Save or share a copy

Select "Share PDF" to use the device’s system sharing options. The selected receiving app or service controls what happens after the file is handed to it. Deleting a RecordLog project or account does not delete copies previously exported, saved elsewhere or shared with another person or service.

Local Storage, Cloud Synchronisation and Offline Use

RecordLog keeps durable app photograph files on the device and uses Google Firebase for authentication and cloud-record features. Pending photograph and project changes can synchronise when connectivity is available. A project can be created and photographs can be saved locally while offline, but fresh GPS is treated as unavailable offline and the PDF-locking step requires internet access. Cloud synchronisation is not a guarantee against loss. Keep separate copies of records that are important to you.

Deleting Records and Your Account

Delete a photograph or project

Use the available in-app controls to delete a photograph or project. RecordLog removes the item from the visible project and, where cloud cleanup is required, performs or queues deletion of the corresponding current Firestore record, expected Firebase Storage image and applicable local app file. If cleanup cannot complete immediately, the app can retain a deletion request and retry when connectivity returns.

Delete your account

In the profile area, select "Delete Account", confirm the request and enter the password for the signed-in email-and-password account. After successful reauthentication, RecordLog begins deleting the account and associated data handled by its current deletion process. It deletes and verifies current project and photograph records found in its implemented Firebase paths and expected Firebase Storage images before deleting the Firebase Authentication account, then clears applicable local application files and records.

If remote deletion or verification fails before the Authentication account is deleted, RecordLog reports that the account was not removed and you can retry. If local cleanup fails after the Authentication account has been deleted, the account is already deleted and RecordLog signs out.

Account deletion cannot remove PDFs, photographs or other files previously exported, saved elsewhere or shared outside RecordLog. It does not guarantee immediate removal from service-provider backups or logs and may not identify historical orphaned records outside the current implemented paths. Contact DATALOG PTY LTD if you need help with a deletion request.

Troubleshooting

I cannot import a photograph from the device photo library

RecordLog currently captures photographs through its in-app camera and does not support photo-library imports.

GPS is unavailable or unchanged

Check that the device is online, location services are on and RecordLog has location permission. Location accuracy and movement detection depend on the device, signal and surroundings. You can continue with GPS off if coordinates are not required.

My photograph has not appeared in the cloud record

Keep the app installed and reconnect the device to the internet so pending synchronisation can retry. Do not treat cloud synchronisation as your only backup of an important record.

My project did not lock

Confirm that the device has an internet connection and try the PDF-generation and locking step again. The project remains editable unless RecordLog confirms that locking completed. A generated or shared PDF does not by itself prove that the project was locked.

I need more help

Email developer@datalog.com.au with a brief description of the issue, the device model, the iOS version and the RecordLog version. Do not include passwords or sensitive photographs unless DATALOG PTY LTD specifically requests information through an appropriate support process.
