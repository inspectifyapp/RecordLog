About RecordLog

Document anything, keep a clear record.

Coming soon to the App Store

What RecordLog is for

RecordLog is a camera app for creating clear, structured photo records. Use it to document property, vehicles, equipment, belongings, site conditions, or other ordinary personal and business records. Create a project, capture photos, add useful details, and generate a structured PDF copy ready to save or share.

What’s included

  • Structured PDF export

    Generate an organised, shareable PDF copy containing your captured photos, labels, and notes.

  • Organised by area

    Group photos by room, area, or section, and reorder them before generating the record.

  • Optional GPS

    When enabled, RecordLog obtains location coordinates from the device when each photo is captured. Accuracy can vary with the device and surroundings.

  • Server timestamps

    When connectivity is available, a server timestamp provides a consistent time record separate from GPS.

  • Locked records

    Once generated, the record is locked against further editing so it remains intact as created.

  • SHA-256 file fingerprints

    A SHA-256 file fingerprint is calculated for each captured photo as part of its record. It is not certification or proof of authenticity.

Who uses RecordLog

RecordLog is for people and businesses that need clear, dated photo records with useful context. Examples include property, vehicles, equipment, belongings, site conditions, insurance or warranty documentation, expenses, and general household or business record-keeping.

How it works

1. Create a project

Give the record a clear name and add an optional location or address.

2. Capture photos in RecordLog

Use the RecordLog camera. Optional GPS is obtained from the device at capture, and server timestamps require connectivity.

3. Add notes and labels

Add a title, area label, and optional notes to give each photo useful context.

4. Review and organise

Review photos by area, reorder them, and correct details before generating the record.

5. Generate and export

Generate a locked record and export a structured, watermarked PDF copy to save or share.

Documentation tool only

RecordLog does not inspect, assess, certify, verify, or formally validate a condition. It is not legal, medical, financial, tax, or professional advice.
