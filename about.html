About RecordLog

Version: 2.0 · Effective date: 08/10/2026

What RecordLog Is

RecordLog is a general-purpose photo documentation and organisation application published and operated by DATALOG PTY LTD. It helps you create projects, capture photographs, add concise details, organise the result and generate a structured PDF. RecordLog is designed for everyday documentation, including personal projects, hobbies, home DIY, belongings, collections, equipment and other records you choose to keep.

What’s Included

Projects & Camera

Create multiple projects with a project name, an optional location and a project-level GPS setting. Each project supports a maximum of 12 photographs. RecordLog captures new photographs through its in-app camera; importing photographs from the device photo library is not currently supported.

Titles & Organisation

Add an optional title of up to 20 characters and an optional note of up to 50 characters to each photograph. Review and reorder photographs before generating the project PDF. RecordLog does not currently provide a separate category, area or label field.

Timestamps & GPS

RecordLog creates a capture date and time from the device when each photograph is taken. The timestamp is not server generated and remains independent of GPS availability. While the RecordLog camera is active, the app may request and obtain device location. GPS is optional at the project level. RecordLog stores coordinates with a new photograph only when project GPS is enabled and an appropriate location is available. The current app treats GPS as unavailable while offline, and accuracy varies with the device, signal and surroundings.

PDF & Project Locking

Generate a structured PDF from the project information, photographs and available details. RecordLog creates the PDF locally and makes it available through the device’s system sharing options. An internet connection is required to complete the project-locking step. After that step succeeds, the project is locked against further editing in RecordLog. Start a new project if you need a revised record.

Storage & Photo Hashes

Saved photographs are kept in RecordLog’s app storage on the device and queued for cloud synchronisation. Account and cloud-record features use Google Firebase. RecordLog also calculates a SHA-256 hash from the captured image file on the device. The hash is a technical fingerprint that can help compare file contents; it does not certify the photograph, prove when or where it was taken, or independently establish authenticity. Cloud synchronisation is not a substitute for keeping your own copies of important records.

How It Works

  1. Create a project. Enter a project name, add an optional location and choose whether GPS is enabled.
  2. Capture photographs. Use the RecordLog camera to take up to 12 photographs. RecordLog creates a device-generated capture timestamp for each photograph and, when enabled and available, stores GPS coordinates.
  3. Add details. Add an optional title and note to give each photograph context.
  4. Review and organise. Review the project photographs and reorder them before generating the PDF.
  5. Generate the record. Generate a structured PDF, complete the online project-locking step and use the device’s system sharing options to save or share a copy.

Documentation Boundary

RecordLog records and organises information supplied or captured by the user. It does not inspect a subject, independently verify photographs or metadata, certify a condition, guarantee accuracy, or determine whether a record is suitable for a particular purpose. Device time, location services, user-entered information, connectivity and other technical conditions can affect the contents of a record.
